# TuningFork

A reference-tone generator for OVOS - 'give me an A' plays a 440Hz tone (or any named musical note/frequency), useful for tuning instruments offline. Generated sine tone, no audio samples needed.

> **This is a skeleton only - not implemented yet.** Repo, structure,
> and design notes are in place; the actual skill logic hasn't been
> written. See "Design notes" in [DEVELOPMENT.md](DEVELOPMENT.md).

## Why this exists

Nothing like this exists in the OVOS ecosystem yet (checked before starting). Fully deterministic - a generated sine wave at a known frequency, no cloud dependency.

## Planned usage (not yet functional)
```
"give me an A"
"play a concert A"
"play 440 hertz"
```
